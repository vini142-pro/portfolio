# 🌐 VINI SHEKHAR — Portfolio Website

A personal portfolio website built with pure HTML, CSS, and JavaScript. Clean, responsive, and fully self-editable.

---

## 📁 Project Structure

```
portfolio/
├── index.html       # Main HTML file
├── style.css        # All styling
├── script.js        # Animations & interactions
└── ofpic.jpeg       # Your profile photo
```

---

## 🚀 How to Run Locally

1. Clone or download this repository
2. Open `index.html` in your browser
   - Or use **VS Code Live Server** extension for hot reload

```bash
# If using Live Server (VS Code)
Right click index.html → Open with Live Server
```

---


## ✨ Features

- Animated hero section with glowing blobs
- Fixed glassmorphism navbar
- Smooth scroll & fade-in animations
- Responsive on mobile & desktop
- Skills hover effects
- Timeline-style achievements
- Dark contact section

---

## 🛠️ Built With

- HTML5
- CSS3 (no frameworks)
- Vanilla JavaScript
- Google Fonts (Playfair Display + DM Sans)
